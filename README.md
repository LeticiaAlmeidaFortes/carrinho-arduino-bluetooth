# carrinho-arduino-bluetooth

Projeto de um veículo robótico móvel controlado remotamente por um aplicativo de celular (Android). O sistema permite o controle de direção e velocidade em tempo real.

Funcionalidades
- Controle Remoto: Direção (Frente, Trás, Esquerda, Direita) controlada via interface mobile.
- Conectividade: Comunicação sem fio (Bluetooth/WiFi) entre o celular e o microcontrolador.
- Mobilidade: Controle de motores DC através de driver de potência (Ponte H).

Tecnologias
- Arduino UNO 
- Módulo Bluetooth (HC-05)
- Ponte H (L298N)
- Conversor de nível lógico
